# Agent Guidelines

## Design & UI Tasks
For any UI/design work (designing, building, redesigning, styling, or auditing interfaces), follow the design skills in `.agents/skills/`:

### 1. Architectural System & Anti-Slop Gate ([`ui-ux-kit`](file:///d:/Antigravity/.agents/skills/ui-ux-kit/SKILL.md))
- **Routing**: Profile surface (landing, dashboard, app, mobile, store, docs).
- **Concept & Taste**: Commit to one distinctive idea, OKLCH color (60/30/10), computed contrast, states, and performance levers.
- **Build & Quality Floor**: Token-first CSS, responsive down to mobile, visible keyboard focus, reduced motion.
- **Adversarial Self-Review**: Hard bans against generic templates, reflex hero splits, off-screen tooltips, and raw black/white.
- **Documentation**: Maintain and update `DESIGN_SYSTEM.md`.

### 2. Creative Direction & Intentionality ([`frontend-design`](file:///d:/Antigravity/.agents/skills/frontend-design/SKILL.md))
- **Subject-Matter Grounding**: Draw aesthetic vernacular directly from the product's domain, materials, and audience rather than generic SaaS tropes.
- **Typographic Discipline**: Intentional font pairing, type scales from *The Elements of Typographic Style*, <80 char line lengths. Never use single-word accenting or all-caps eyebrows as defaults.
- **Restraint**: Spend boldness in one place; keep everything else quiet and disciplined ("remove one accessory"). Non-user motion only for deliberate moments.
- **Copywriting**: Active voice, end-user perspective, unambiguous signposting, and no filler.
